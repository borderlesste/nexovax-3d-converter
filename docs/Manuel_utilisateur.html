NEXOVAX 3D Converter — Manuel d'utilisation

Version 1.0 · Application de bureau pour Windows 10/11 (64 bits) qui convertit des modèles 3D entre glTF, GLB, OBJ, FBX, STL, IFC, STEP et IGES sans connexion Internet.

1. Premiers pas

  1. Ouvrez NEXOVAX 3D Converter depuis le raccourci du bureau ou le menu Démarrer.
  2. Cliquez sur Ajouter des fichiers (Ctrl+O), Ajouter un dossier, ou glissez des fichiers et dossiers dans la fenêtre.
  3. Choisissez le Format cible dans le panneau Configuration.
  4. Choisissez éventuellement un Dossier de sortie (s'il est vide, chaque résultat est enregistré à côté de son fichier source).
  5. Cliquez sur CONVERTIR (F5). Ensuite, utilisez Ouvrir le dossier de destination.
  6. Langue : choisissez Español, Français ou Kreyòl ayisyen dans le sélecteur de l'en-tête (l'application redémarre).
Le fichier d'origine n'est jamais modifié. Si un fichier du même nom existe déjà, nom (1).ext est créé, sauf si l'option « Écraser les fichiers existants » est activée.

2. L'interface

Panneau « Fichiers » (gauche)

Liste des modèles avec nom, extension, taille et état. La case à cocher indique si le fichier sera converti. Le format est détecté d'après le contenu réel du fichier et pas seulement l'extension ; en cas de différence, un avertissement apparaît dans le journal. Clic droit : tout cocher/décocher, ouvrir le dossier, voir le rapport, retirer de la liste. Le champ Filtrer les fichiers (Ctrl+F) filtre la liste par nom.

ÉtatSignification
En attenteAjouté, non converti.
En file / En conversionFait partie du lot en cours.
ConvertiRésultat généré et validé sans incident.
Avec avertissementsRésultat valide, avec des pertes d'informations documentées ou des hypothèses (par ex. les unités d'un STL).
ÉchecAucun fichier n'a été généré. La cause figure dans le journal et le rapport.
AnnuléArrêté par l'utilisateur ; aucun fichier partiel ne reste.

Panneau « Aperçu 3D » (centre)

Affiche le fichier sélectionné. Rotation : bouton gauche · Déplacer : bouton central (ou Maj+gauche) · Zoom : molette. Boutons : vue isométrique, centrer, zoom avant/arrière, mode Ombré / Filaire / Ombré + arêtes, grille, axes XYZ et plein écran (F11). L'encadré Dimensions du modèle donne la taille en mètres (X, Y, Z avec Z vertical) et le volume lorsque le modèle est fermé. L'aperçu est calculé dans un processus séparé : il ne bloque jamais la conversion ni l'interface.

Panneau « Configuration » (droite)

Affiche le format détecté, le chemin de conversion utilisé (avec son niveau de fidélité) et toutes les options. Les options sans effet sur la conversion choisie sont désactivées. Le bouton Profils enregistre et rappelle des configurations nommées.

Panneau « Traitement » (bas)

Barre de progression, temps écoulé et estimé, File de conversion (double-clic = rapport complet), Journal horodaté (enregistrable) et l'encadré Perte d'informations possible, qui annonce les pertes avant la conversion puis montre ce qui s'est réellement passé.

3. Convertir des fichiers

Vous pouvez convertir de nombreux fichiers de formats différents vers un même format cible. Chaque fichier est traité dans un processus isolé : si un fichier endommagé fait échouer un moteur, seule cette tâche échoue et le reste du lot continue. Annuler arrête la tâche en cours et celles en attente en toute sécurité.

Chaque corps fermé devient un solide. En cas d'échec, le journal indique l'étape et la cause, et le journal de diagnostic (%LOCALAPPDATA%\NEXOVAX3DConverter\logs) contient tout le détail technique. CLI : --no-simplify, --target-triangles N, --no-repair, --no-unify.
Limite de triangles → CAOAu-delà, la conversion maillage → STEP/IGES est refusée, car le B-Rep facettisé serait énorme et peu utile.
Valider le résultatRelit le fichier généré et le compare au modèle (recommandé).

5. Résultats, validation et rapports

Après l'écriture de chaque fichier, l'application vérifie qu'il existe et n'est pas vide, le relit, contrôle la présence de géométrie, compare la boîte englobante et le nombre d'objets, puis le lit avec un lecteur indépendant (Assimp pour les maillages, contrôle topologique OCCT pour STEP/IGES, validation de schéma IfcOpenShell pour IFC). Le fichier n'est copié dans le dossier de destination que si la validation réussit (écriture atomique).

6. Ce qui est conservé

TypeExemplesCe qui se passe
DirecteOBJ→GLB, GLB→FBX, STEP→IGES, IFC→STEPMême représentation géométrique. IFC→STEP conserve le B-Rep exact de chaque élément.
TessellationSTEP→STL, IGES→GLB, IFC→OBJSurfaces exactes converties en triangles selon la tolérance.
FacettiséeSTL→STEP, OBJ→IGESChaque triangle devient une face plane : B-Rep valide (solide si le maillage est fermé) mais pas un modèle CAO paramétrique.
LimitéeOBJ→IFC, STEP→IFCIFC valide avec des éléments génériques IfcBuildingElementProxy. Aucune information BIM n'est inventée.
Les animations, squelettes, caméras et lumières FBX/glTF ne sont pas converties : la géométrie est exportée dans sa pose statique.

7. Ligne de commande

nexovax3d-cli.exe convert piece.step -t stl -o C:\Sortie --quality alta
nexovax3d-cli.exe convert C:\Modeles -r -t glb --report rapport.json
nexovax3d-cli.exe --lang fr matrix
nexovax3d-cli.exe convert --help

Code de sortie 0 si toutes les conversions réussissent, 1 si l'une échoue. Langue : --lang es|fr|ht.

8. Résolution des problèmes

SymptômeCause probable et solution
« Format non reconnu »Le contenu ne correspond à aucun des 8 formats ou le fichier est endommagé.
« Fichier auxiliaire de géométrie manquant »Un .gltf a besoin de son .bin (et de ses textures) dans le même dossier.
Modèle trop grand ou trop petitVérifiez les Unités source des OBJ/STL ou utilisez Échelle.
Modèle couchéAjustez l'Orientation des axes (OBJ/STL).
Maillage → STEP refuséLa limite de triangles est dépassée. Simplifiez le maillage ou augmentez la limite.
Aperçu indisponibleL'ordinateur ne dispose pas d'OpenGL 3.2 (certaines machines virtuelles). La conversion fonctionne quand même.

9. Fonctionnement hors ligne et confidentialité

Tous les moteurs sont inclus dans l'installation. L'application n'utilise aucun service en ligne, ne demande ni compte ni activation, ne télécharge rien et n'envoie aucune donnée. Les fichiers temporaires sont créés dans %TEMP%\u3dc et supprimés à la fin. Les références externes des modèles ne sont lues que dans le dossier du modèle ; les URL et chemins sortant de ce dossier sont bloqués.
