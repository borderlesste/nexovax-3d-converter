## NEXOVAX 3D Converter 1.0.0

**ES** — Conversor 3D para Windows 10/11 (64 bits), sin conexión a Internet: glTF, GLB, OBJ, FBX, STL, IFC, STEP e IGES
(las 64 combinaciones). Interfaz en español, francés y criollo haitiano.

**FR** — Convertisseur 3D pour Windows 10/11 (64 bits), sans connexion Internet : glTF, GLB, OBJ, FBX, STL, IFC, STEP et IGES
(les 64 combinaisons). Interface en espagnol, français et créole haïtien.

**HT** — Konvètisè 3D pou Windows 10/11 (64 bit), san entènèt: glTF, GLB, OBJ, FBX, STL, IFC, STEP ak IGES
(tout 64 konbinezon yo). Entèfas an panyòl, fransè ak kreyòl ayisyen.

### Instalación · Installation · Enstalasyon
1. Descargue / Téléchargez / Telechaje `NEXOVAX3DConverter-Setup.exe`.
2. Ejecútelo / Lancez-le / Lanse l. No requiere administrador · Pas besoin d'administrateur · Pa bezwen administratè.
3. Compruebe la suma / Vérifiez la somme / Verifye sòm nan: `SHA256SUMS.txt`.

Si Windows SmartScreen muestra «Windows protegió su PC», pulse *Más información → Ejecutar de todas formas*
(el instalador aún no está firmado digitalmente).
