# Third-party components · Componentes de terceros · Composants tiers

The MIT license in `LICENSE.txt` covers the NEXOVAX 3D Converter source code only.

The installer bundles third-party libraries — Qt/PySide6, Open CASCADE (OCP), VTK, IfcOpenShell, NumPy, trimesh,
ufbx, Assimp, Pillow, Python and others — distributed under their own licenses (LGPL, BSD, MIT, Apache 2.0, PSF).
They are dynamically linked and can be replaced in the `_internal` folder of the installation.

Full list with versions and license texts: [docs/LICENCIAS_TERCEROS.html](docs/LICENCIAS_TERCEROS.html).
